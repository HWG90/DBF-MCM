# UI polish

The UI uses stock primitives, separate background/control/text depths, retained geometry, quieter colors and scoped label scrolling. Settings persists Open/Close, window dimensions, UI scale and font size. Confirmation and defaults use buttons.

See [0.1.53 release notes](RELEASE-0.1.53.md), [architecture](ARCHITECTURE.md) and the [author quick start](AUTHOR-GUIDE.md). Actual-compose previews and package receipts are local build outputs; they do not prove live appearance or input behavior.
